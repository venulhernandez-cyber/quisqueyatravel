Instalación en quisqueyatravel.org

Para que este agente funcione en tu sitio web real, simplemente copia el siguiente fragmento de código e insértalo justo antes de la etiqueta de cierre </body> en tu HTML.

Código HTML / JS de Integración 
<!-- Quisqueya Travel AI Agent Widget -->
<script src="./js/widget.js" data-agent-id="quisqueya-sales" defer></script>

Pasos para la puesta en marcha:

  1. Configura tu API Key: Asegúrate de ingresar tu clave en la pestaña de configuración.
  2. Despliegue de producción: Para producción, sube el archivo widget.js a tu servidor o CDN y reemplaza el enlace de localhost por tu URL real.
  3. Seguridad: El widget ya no llama a Gemini directamente desde el navegador. Todas las peticiones pasan por la función serverless /api/chat (Cloudflare Pages Functions), que usa tu API Key guardada como variable de entorno secreta en Cloudflare — nunca viaja al navegador del visitante.

Por seguridad, la API Key ya no se guarda en el navegador. Configúrala como variable de entorno secreta GEMINI_API_KEY en Cloudflare Pages > tu proyecto > Settings > Environment variables.
